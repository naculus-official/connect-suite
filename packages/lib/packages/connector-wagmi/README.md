# @naculus/connector-wagmi

Wagmi connector adapter for Naculus Connect — bridge between wagmi hooks and Naculus Connect's connector system.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-wagmi
# or
pnpm add @naculus/connector-wagmi
```
