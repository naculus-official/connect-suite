# @naculus/connect-core

Core interfaces and connector manager for Naculus Connect — the foundation all connectors plug into. Defines `UniversalConnector`, `ConnectorManager`, session types, and chain abstractions.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once, or install only the connectors you need alongside this core.

## Install

```bash
npm install @naculus/connect-core
# or
pnpm add @naculus/connect-core
```
