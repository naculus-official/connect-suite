# @naculus/connector-passkeys

Passkeys / WebAuthn connector for Naculus Connect — passwordless authentication using platform biometrics (Face ID, Touch ID, Windows Hello).

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-passkeys
# or
pnpm add @naculus/connector-passkeys
```
