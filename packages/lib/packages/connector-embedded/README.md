# @naculus/connector-embedded

Embedded wallet connector for Naculus Connect — non-custodial in-app wallet powered by PocketWallet bridge (BIP39 HD wallet created client-side).

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-embedded
# or
pnpm add @naculus/connector-embedded
```
