# @naculus/connector-safe

Gnosis Safe SDK connector for Naculus Connect — connect to Safe multi-signature wallets.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-safe
# or
pnpm add @naculus/connector-safe
```
