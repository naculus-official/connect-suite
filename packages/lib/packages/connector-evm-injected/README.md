# @naculus/connector-evm-injected

EIP-6963 browser wallet connector for Naculus Connect — auto-detects injected EVM wallets (MetaMask, Rabby, etc.) via the EIP-6963 Multi Injected Provider discovery protocol.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-evm-injected
# or
pnpm add @naculus/connector-evm-injected
```
