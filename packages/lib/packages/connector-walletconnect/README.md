# @naculus/connector-walletconnect

WalletConnect v2 connector for Naculus Connect — connects dApps to mobile wallets via QR code / deep link.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-walletconnect
# or
pnpm add @naculus/connector-walletconnect
```
