# @naculus/wallet-engine

Embedded wallet engine for Naculus Connect — BIP39 mnemonic generation, HD key derivation (BIP32/BIP44), and transaction signing. Powers the embedded wallet connector.

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all packages at once.

## Install

```bash
npm install @naculus/wallet-engine
# or
pnpm add @naculus/wallet-engine
```
