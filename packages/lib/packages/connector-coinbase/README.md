# @naculus/connector-coinbase

Coinbase Wallet SDK connector for Naculus Connect — connect to Coinbase Wallet (browser extension & mobile).

> **Part of [@naculus/connect](https://www.npmjs.com/package/@naculus/connect)** — install the umbrella package to get all connectors at once.

## Install

```bash
npm install @naculus/connector-coinbase
# or
pnpm add @naculus/connector-coinbase
```
